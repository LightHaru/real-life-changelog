A single-line patch note for a bug in real life, shipped by a dependency-free
Node 22.18+ program. Writes one comedy changelog entry (160 characters max) to
`entry.txt` in the output directory — `/output` by default.

## Run it

```sh
node main.ts            # writes /output/entry.txt
node main.ts ./output   # or any output directory
node --test             # smoke test
```
